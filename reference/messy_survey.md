# Messy Survey Dataset

Example dataset containing messy column names and inconsistent date
formatting for demonstrating pristineR functions.

## Usage

``` r
messy_survey
```

## Format

A data frame with 5 rows and 3 variables:

- Student.Name:

  Character vector of student names

- Exam.Score.:

  Numeric exam scores in percent

- Submission.Date:

  Character vector of mixed-format dates
